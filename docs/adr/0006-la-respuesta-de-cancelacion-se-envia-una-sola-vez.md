# La Respuesta de cancelación se envía una sola vez

Aceptar una cancelación no se puede deshacer, así que el Envío de respuesta corre en un job de cola sin reintentos automáticos, a diferencia de la descarga de Paquetes. Si el envío termina sin Acuse de respuesta (fault, respuesta ilegible, sin conexión o el worker se cayó), la Cancelación pendiente queda en Envío incierto y solo se permite volver a enviarla cuando una Revisión de cancelaciones posterior al envío la sigue mostrando pendiente, señal de que el SAT no la registró. Descartamos reintentar automáticamente porque un reintento podría duplicar una respuesta que sí llegó, y descartamos dejar el reenvío libre porque el usuario no tiene forma de saber si el primero llegó. Si el SAT responde con un código de error (2002, 30002, 30005), sabemos que no la procesó y la Cancelación pendiente vuelve a Por responder.
