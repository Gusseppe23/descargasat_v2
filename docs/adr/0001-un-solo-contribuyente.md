# Un solo contribuyente por aplicación

La aplicación atiende a un solo contribuyente (un RFC). Sus Fiel pertenecen a la aplicación, no a cada usuario: todos los usuarios autenticados comparten las mismas Fiel, Solicitudes y Paquetes, y ninguno tiene rol especial. Se pueden guardar varias Fiel (por ejemplo, la vieja y la renovada), pero todas deben ser del mismo RFC y solo una puede ser la Fiel activa; se rechaza subir una Fiel de otro RFC. Elegimos esto sobre "una Fiel por usuario" y "equipos con varios contribuyentes" porque así no hace falta aislar datos entre usuarios. Por eso las tablas de Fiel, Solicitud y Paquete no tienen un dueño, solo registran qué usuario hizo cada acción. Atender a varios contribuyentes después exigiría agregar un dueño (equipo o empresa) a todas esas tablas.
